# Project Rules & Constraints

## Definition of Done (Kriteria Selesai)
- Setiap kali Anda memodifikasi, menambah, atau menghapus file kode komponen/fitur di dalam repositori ini, Anda WAJIB memeriksa dan memperbarui file `README.md` agar dokumentasi tetap selaras dengan perubahan kode terakhir.
- Tugas dianggap belum selesai sebelum file `README.md` diperbarui mengikuti perubahan kode yang Anda buat.
